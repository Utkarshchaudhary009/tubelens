# TubeLens Developer Docs

API-first YouTube data API built on Next.js Route Handlers + youtubei.ts.

- Base URL: `/api/v1` — full contract served live at `/api/v1/openapi.json`.
- Start with [Quickstart](/docs/quickstart), then [API Overview](/docs/api/overview).
- Conventions: cursor pagination, typed errors with hints, `X-Request-Id` + `X-RateLimit-*` headers.
- Internal planning artifacts live in `plans/` (owner-only, never published here).
